# Anciennes listes de demandes

Ces fichiers sont conservés pour retrouver les retours, descriptions et relations originales.
Ils ne sont plus la feuille de route active : utiliser `../../../A_FAIRE.md`.

- `a faire.txt` : ancien suivi des demandes avec statuts historiques, parfois devenus obsolètes.
- `a faire - original.txt` : demandes et retours initiaux.
- `a faire(1).txt` : copie identique du fichier original, vérifiée par SHA-256 avant classement.

Archivage le 5 octobre 2026, sans modification du contenu des originaux.
