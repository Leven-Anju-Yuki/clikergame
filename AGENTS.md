# Consignes de suivi du projet

À la demande de l’utilisateur, regrouper les mises à jour de README (arborescence et poids), A_FAIRE, documentation et Trello dans le bilan quotidien de 23 h, fuseau Europe/Paris. Ne pas les réécrire pendant chaque tâche de la journée, sauf demande explicite.

Lors du bilan : inspecter les modifications effectives, actualiser les documents et poids, mettre à jour les cartes Trello existantes plutôt que multiplier les doublons, et signaler les points restant à valider. Ne pas publier ni pousser le projet.

Cette consigne ne programme pas une exécution : une tâche planifiée doit être activée dans l’application.
